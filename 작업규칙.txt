# 1단계: SmartHeightManager를 “에디터 전용 테스트 오프셋”으로 수정

## 목표

* 에디터에서는 눈높이 올려서 테스트 가능
* 빌드에서는 SmartHeightManager가 **아예 아무 것도 안 함**

## 1-1. SmartHeightManager.cs 패치

아래처럼 바꿔. (중요: **Update에서 매 프레임 강제하지 말고 1회 적용**)

```csharp
using UnityEngine;

public class SmartHeightManager : MonoBehaviour
{
    [Header("Editor/Simulator Test Only")]
    public bool enableEditorOffset = true;

    [Tooltip("Title/Start scene simulated eye height (meters)")]
    public float titleEyeHeight = 0.0f;

    [Tooltip("Gameplay simulated eye height (meters)")]
    public float gameEyeHeight = 1.7f;

    [Tooltip("True = use gameEyeHeight, False = use titleEyeHeight")]
    public bool useGameHeight = false;

    [Tooltip("Apply once on Start (recommended).")]
    public bool applyOnStart = true;

#if UNITY_EDITOR
    private Transform trackingSpace;

    private void Awake()
    {
        // OVR 구조상 TrackingSpace는 OVRCameraRig 아래에 있음
        // 이 스크립트가 어디 붙든, 자식에서 TrackingSpace를 찾아온다.
        trackingSpace = GetComponentInChildren<Transform>(includeInactive: true);
    }

    private void Start()
    {
        if (!enableEditorOffset) return;
        if (applyOnStart) ApplyHeightOnce();
    }

    [ContextMenu("Apply Height Once (Editor)")]
    public void ApplyHeightOnce()
    {
        if (!enableEditorOffset) return;

        // TrackingSpace 찾기(안전하게)
        var ts = FindTrackingSpace();
        if (ts == null) return;

        float y = useGameHeight ? gameEyeHeight : titleEyeHeight;

        var p = ts.localPosition;
        p.y = y;
        ts.localPosition = p;
    }

    private Transform FindTrackingSpace()
    {
        // 흔히 "TrackingSpace" 이름으로 존재
        var rigs = FindObjectsOfType<Transform>(true);
        foreach (var t in rigs)
        {
            if (t.name == "TrackingSpace")
                return t;
        }
        return null;
    }
#else
    // Build에서는 완전 무효
    private void Start() { }
#endif
}
```

### 이 패치의 핵심

* `#if UNITY_EDITOR`로 **빌드에서 완전 무효**
* `Update()` 제거 → **매 프레임 강제 삭제**
* 에디터에서 필요할 때만 “한 번 적용” 가능 (`ContextMenu`)

## 1-2. 인스펙터 설정(추천)

SmartHeightManager 컴포넌트에서:

* enableEditorOffset = **true**
* applyOnStart = **true**
* useGameHeight = 씬에 따라:

  * Main(타이틀 테스트): false (0.0)
  * Stage(플레이 테스트): true (1.7)

✅ 완료 조건:
에디터에서 플레이하면 높이가 올라가고, 빌드에서는 영향이 0.
